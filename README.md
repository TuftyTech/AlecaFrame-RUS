# AlecaFrame-RU

Неофициальный **русский интерфейс для [AlecaFrame](https://alecaframe.com/)** — приложения-компаньона для Warframe, которое работает внутри Overwolf.

![AlecaFrame на русском: вкладка «Реликвии»](docs/preview-ru.png)

<sub>Окно AlecaFrame 2.6.90 в тестовом стенде без данных игры: поэтому списки пустые. Это не снимок из живого Overwolf.</sub>

## Что это

Небольшой скрипт перевода. Он подключается к страницам AlecaFrame и заменяет английский текст на русский: меню, кнопки, настройки, подсказки, оверлеи реликвий и модов Разлома, TennoFinder, список изменений. Переведено 900 из 900 строк версии AlecaFrame 2.6.90. Терминология взята из официальной русской версии Warframe: Литейная, Моды Разлома, Реликвии, Стальной Путь и т. д.

Там, где русский текст длиннее английского, подправлены отступы, чтобы ничего не обрезалось.

## Чего это не делает

- **Не убирает и не прячет рекламу.** Рекламные блоки перевод обходит стороной.
- **Не трогает подписку, Patreon и платные функции**, включая платные темы.
- Не меняет программу AlecaFrame (DLL, логику, данные) и файлы игры.
- Не переводит то, что уходит другим людям: сообщение продавцу на WFMarket и уведомления в Discord остаются на английском.

## Что нужно

- Windows 10 или 11.
- [Overwolf](https://www.overwolf.com/) с установленным **AlecaFrame**, который вы хотя бы раз открывали.
- Больше ничего. Node.js, Python и другие программы не нужны.

## Установка и запуск

1. Нажмите на этой странице **Code → Download ZIP** и распакуйте архив в **постоянную папку**, например `C:\Tools\AlecaFrame-RU`. Не в «Загрузки» и не во временную: после установки папку нельзя перемещать.
2. Выйдите из игры. Если Overwolf запущен, это нормально: скрипт закроет его сам.
3. Дважды щёлкните **`Start.cmd`**.
   - Windows может показать предупреждение SmartScreen: файл скачан из интернета. Это обычные текстовые скрипты, их можно открыть в Блокноте. Нажмите «Подробнее → Выполнить в любом случае».
4. При первом запуске появится описание того, что будет сделано (см. раздел «Важно про безопасность»). Если согласны, введите `да` и нажмите Enter.
5. Подождите: это может занять пару минут. Overwolf перезапустится, AlecaFrame откроется сразу на русском. В окне появится надпись «Готово».
6. **Не закрывайте чёрное окно**, пока пользуетесь AlecaFrame. Закончили — выйдите из Overwolf (значок в трее → Exit). Файлы AlecaFrame вернутся в исходное состояние, окно закроется само.

В следующий раз запускайте так же — через `Start.cmd`. Удобно создать ярлык: правый щелчок по `Start.cmd` → «Отправить → Рабочий стол (создать ярлык)».

Если запустить AlecaFrame обычным способом, через Overwolf, он откроется на английском: это нормально, перевод включается только через `Start.cmd`.

## Как вернуть всё как было

Дважды щёлкните **`Uninstall.cmd`**. Он закроет Overwolf, вернёт исходные файлы AlecaFrame и удалит служебную папку `%LOCALAPPDATA%\AlecaFrame-RU`. Потом можно просто удалить папку с проектом.

## Если что-то пошло не так

| Что видите | Что делать |
| --- | --- |
| AlecaFrame не открывается или сразу закрывается при обычном запуске | Запустите `Uninstall.cmd`. Так бывает, если окно закрыли, не выйдя из Overwolf: часть файлов осталась изменённой. Если не помогло, переустановите AlecaFrame через Overwolf. |
| «Overwolf закрыл AlecaFrame из-за проверки целостности (HashMismatch)» | Ваша сборка Overwolf не принимает такой способ подключения. Файлы возвращены, AlecaFrame работает на английском. Создайте [issue](../../issues) и приложите `launcher.log` (см. ниже). |
| «Перевод не загрузился» | Создайте issue и приложите `launcher.log`. |
| Часть надписей осталась на английском | Скорее всего, ваша версия AlecaFrame новее 2.6.90. Создайте issue со скриншотом: переведём. |

Журнал запуска: `%LOCALAPPDATA%\AlecaFrame-RU\launcher.log` (вставьте этот путь в адресную строку Проводника).

## Важно про безопасность

Overwolf проверяет файлы каждого приложения по подписанному списку, и изменённый AlecaFrame он закрывает. Поэтому любой способ подключить перевод требует отключить эту проверку. Здесь это делается так:

- `Start.cmd` запускает Overwolf с флагом `--ow-disable-features=extension-validation,read-opk-from-memory`;
- проверка отключается **для всех приложений Overwolf**, а не только для AlecaFrame, и **только пока открыто окно запуска**. Когда вы выходите из Overwolf, файлы возвращаются в исходное состояние, а обычный запуск снова идёт с проверкой;
- в 9 страниц AlecaFrame добавляется одна строка `<script src="assets/js/alecaframe-ru.js">`, больше ничего не меняется. Удаление этой строки побайтово возвращает файл в исходный вид, это проверяется тестами;
- пока окно открыто, другие приложения Overwolf не проверяются на подмену. Если вы не готовы на это, пользуйтесь AlecaFrame на английском.

Такой же способ используют существующие китайские переводы AlecaFrame. Более широкий флаг `force-validation-report-only`, который понадобился им на новых сборках Overwolf, здесь **намеренно не используется**.

Автор AlecaFrame не поддерживал и не проверял этот проект. Используйте на свой риск.

## Для разработчиков

Нужны Node.js 22.22+ (или 24.15+) и pnpm. Для проверки установщика ещё PowerShell 7 (`pwsh`).

```bash
pnpm install
pnpm test                    # тесты перевода (Node, jsdom, Vue 3.2.31)
pnpm test:windows            # тесты установщика (pwsh)
pnpm extract <папка AlecaFrame>   # собрать строки установленной версии -> strings/en.json
pnpm coverage -- --missing   # что ещё не переведено
pnpm build                   # dist/alecaframe-ru.js: перевод + словарь + стили в одном файле
pnpm preview <папка AlecaFrame>   # скриншоты EN/RU и отчёт о переполнениях в preview-out/
```

Папка AlecaFrame: `%LOCALAPPDATA%\Overwolf\Extensions\afmcagbpgggkpdkokjhjkllpegnadmkignlonpjm\<версия>`. Её содержимое в репозиторий не коммитится.

`dist/alecaframe-ru.js` хранится в репозитории, чтобы работало «Download ZIP». Тест следит, чтобы он совпадал со сборкой: после правок словарей выполните `pnpm build`.

Устройство:

| Часть | Файл | Что делает |
| --- | --- | --- |
| Перевод | `src/localizer.js` | Обходит DOM и через `MutationObserver` переводит текст и атрибуты `title`, `placeholder`, `aria-label`, `data-tippy-content`. Работает с Vue и до, и после запуска приложения |
| Словари | `locales/ru/*.json` | `"English": "Русский"`. Строки с `{0}` — шаблоны, например `"{0} owned": "В наличии: {0}"`. Что переводить нельзя, записано в `locales/ignore.json` |
| Стили | `src/alecaframe-ru.css` | Только отступы под `html[lang="ru"]`, каждое правило подтверждено отчётом превью |
| Установщик | `windows/*.ps1`, `windows/AlecaFrameRU.psm1` | Подключение и возврат файлов, запуск Overwolf |
| Сборщик строк | `tools/extract.mjs` | Достаёт строки из HTML, выражений Vue и JS установленной версии |
| Превью | `tools/preview.mjs` | Открывает `main.html` в headless Chrome с заглушкой Overwolf на EN и RU, листает вкладки, ищет текст, который обрезается только по-русски |

Нюансы, которые легко сломать:
- `.inventoryItemName` не переводится: AlecaFrame читает этот текст обратно и ищет по нему предмет на warframe.market.
- У `<option>` без `value` английское значение закрепляется до перевода, иначе `v-model` получил бы русское.
- Если перевод фрагмента начинается со знака препинания («, чтобы повторить.»), пробел перед ним убирается.
- `window.__AF_RU__.missing()` возвращает тексты, которые встретились без перевода.
- `.cmd` и `.ps1` хранятся в CRLF, а `.ps1` ещё и с BOM (иначе Windows PowerShell 5.1 прочтёт русский текст как ANSI). `.gitattributes` отключает для них преобразование строк.

После выхода новой версии AlecaFrame: `pnpm extract <папка>` → `pnpm coverage -- --missing` → переведите новое в `locales/ru/` → `pnpm build && pnpm test` → `pnpm preview <папка>` и проверьте `preview-out/overflow-report.txt`.
